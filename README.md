# Design-Documents

This repository contains High-Level Design (HLD) and Low-Level Design (LLD) documents for the AI Observability Platform.

## Overview

The aim of this repository is to document the system architecture, component-level details, and design rationale for current and future development. It serves as a reference for all contributors and stakeholders.
